**Lucky Number Generator**

A Python command-line tool that calculates a "lucky number" from a birthday using digit reduction and numerology rules. Also maps the result to a lucky animal and generational label.

**Features**

* Birthday validation (handles leap years, month names, and numeric input)
* Lucky number calculation with master number detection (11, 22, 33)
* Lucky animal and generation mapping
* Profile comparison between two birthdays
* File input support (CSV format)
* Profile saving to file
* Unit tested with pytest (black-box and white-box test coverage)


**Tech**

* Python 3.8+
* pytest
